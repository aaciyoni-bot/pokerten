# מנוע הלידים

איתור עסקים שאין להם אתר אינטרנט, לפי נישה ועיר, ישירות מגוגל.

## מה יש כאן

| קובץ | מה זה |
|---|---|
| `queries.csv` | 120 שאילתות חיפוש — 40 נישות על פני 30 ערים, עם צפי לידים לכל שאילתה |
| `find-leads.mjs` | מריץ את השאילתות מול Google Places API ומשאיר רק עסקים ללא אתר |
| `leads-template.csv` | סכמת טבלת הלידים לניהול השיחות |
| `leads.csv` | הפלט. נוצר בהרצה |

## הרצה

```
export GOOGLE_MAPS_API_KEY=<המפתח שלכם>
node find-leads.mjs --priority א      # 54 השאילתות עם שיעור "אין אתר" הגבוה ביותר
node find-leads.mjs                   # כל 120 השאילתות
```

צריך להפעיל **Places API (New)** בקונסולת Google Cloud ולחייב את הפרויקט. החיוב הוא לפי
בקשה ויש מכסה חינמית חודשית — בדקו את התמחור העדכני בקונסולה לפני הרצה של כל 120 השאילתות.

הסקריפט מסנן החוצה עסק שיש לו אתר, עסק סגור, ועסק בלי מספר טלפון. מה שנשאר זה בדיוק
מי שאנחנו מחפשים.

## הצפי

**עדיפות א לבדה — 54 שאילתות — מייצרת את 500 הלידים הראשונים.**

## איך מדרגים לידים אחרי המשיכה

הסקריפט מביא הכול. לפני שמתקשרים, מסננים בטבלה לפי הסדר הזה:

1. **20 ביקורות ומעלה בגוגל** — סימן לעסק פעיל עם לקוחות, לא רישום מת.
2. **דירוג 4.0 ומעלה** — יש לו מה להראות, והאתר יעבוד לטובתו.
3. **טלפון נייד (05x)** — מגיע ישירות לבעלים, לא למזכירה.
4. **עסק בעיר עם תחרות** — מי שיש לו חמישה מתחרים באותו רחוב מבין מיד למה הוא צריך אתר.

ליד שעונה על כל הארבעה הוא "ליד חם". יעד: 30% מהרשימה.

## חוק — לקרוא לפני השיחה הראשונה

בישראל, סעיף 30א לחוק התקשורת אוסר על משלוח **דבר פרסומת** במסרון, בדוא"ל, בפקס או
בחיוג אוטומטי **ללא הסכמה מראש** של הנמען. הודעת וואטסאפ שיווקית יזומה נחשבת ברוב
הפרשנויות לדבר פרסומת. **שיחת טלפון של נציג אנושי אינה נכללת באיסור הזה.**

לכן סדר הפעולות שלנו הוא:

1. **מתקשרים.** שיחה אנושית, לא הודעה.
2. בסוף השיחה מבקשים אישור מפורש: *"אשלח לך את זה בוואטסאפ, בסדר?"*
3. **רק אחרי "כן" שולחים** את הדמו ואת ההצעה.
4. מתעדים את ההסכמה בטבלה, בעמודה "הסכמה לוואטסאפ", עם תאריך.
5. בכל הודעה משאירים דרך להסיר את עצמו מהרשימה, ומכבדים בקשה כזאת מיד.

זה לא מסבך את המכירה — זה משפר אותה. שיחה קודם ואז דמו ממירה טוב יותר מהודעה קרה.
**זו הבנה כללית ולא ייעוץ משפטי. לפני שמתחילים בקנה מידה, כדאי לאשר את הנוסח עם עורך דין.**
