# ORIZISWEB

אתר השיווק והמכירות של אוריזיס ווב, יחד עם שלדי הנישה ותשתית סגירת העסקה.

## מבנה

| קובץ | מה זה |
|---|---|
| `index.html` | האתר הראשי: הצעת הדמו החינמי, תיק עבודות אמיתי, סוגי אתרים, חבילות ומחירים, פלחי לקוחות, flow העבודה ושאלות נפוצות |
| `portfolio.js` | קטלוג העבודות: שם, קטגוריה, תיאור, קישור חי וצילום מסך. עריכת התיק נעשית בקובץ הזה בלבד |
| `shots/` | צילומי מסך אמיתיים של האתרים שבנינו, 640 פיקסל רוחב |
| `proposal.html` | עמוד ההצעה הדיגיטלית. נשלח כקישור אישי לכל לקוח, כולל אישור וחתימה |
| `STRATEGY.md` | התוכנית העסקית והשיווקית: פילוח לקוחות, מחירון, תוכנית שיווק, תגמול אשת מכירות, תשתיות ו-flow סגירת עסקה |
| `demos/base.css` | ספריית הרכיבים המשותפת. כל שלד נישה טוען אותה ומשנה רק טוקנים |
| `demos/*.html` | שישה שלדי נישה לבניית דמו חינם ללקוח בעשרים דקות: משרד עו"ד, מספרה, מוסך, קליניקה, חנות ודף אירוע. אלה כלי ייצור פנימי, לא תיק העבודות |

## איך מוסיפים עבודה לתיק

1. מצלמים את האתר החי ברוחב 1200 פיקסל, שומרים כ-JPEG ברוחב 640 בתיקיית `shots/`.
2. מוסיפים שורה ל-`portfolio.js` עם שם, קטגוריה, תיאור בשורה אחת, קישור חי ושם קובץ הצילום.
3. קטגוריה חדשה נוצרת מאליה — צ׳יפ הסינון באתר נבנה מהקטגוריות שבקובץ.
4. פריט בלי קישור ציבורי: מציבים `u:null` והכרטיס יוצג בלי לינק, עם הערה מתאימה.

## איך בונים דמו חינם ללקוח ב-20 דקות

1. בוחרים את השלד הקרוב ביותר מתוך `demos/`.
2. משכפלים לקובץ חדש בשם העסק.
3. משנים בראש הקובץ את חמשת הטוקנים בלבד: `--brand`, `--brand-soft`, `--accent`, `--alt`, `--ink`.
4. מחליפים שם, כתובת, טלפון, שירותים ומחירים.
5. מורידים את שורת ה-`ribbon` העליונה כשזה הופך לאתר אמיתי של לקוח.
6. מעלים לכתובת זמנית ושולחים את הקישור בוואטסאפ.

## איך שולחים הצעת מחיר

`proposal.html` נבנה מפרמטרים בכתובת, כך שאשת המכירות מייצרת קישור אישי בלי לגעת בקוד:

```
proposal.html?biz=מספרת+נוגה&name=נוגה+לוי&pack=pro&addons=logo,content&care=plus&discount=10
```

| פרמטר | ערכים |
|---|---|
| `biz` | שם העסק |
| `name` | שם איש הקשר |
| `pack` | `nano` · `one` · `pro` · `business` · `shop` |
| `addons` | רשימה מופרדת בפסיקים: `logo` `content` `lang` `access` `bot` `booking` `photo` `landing` |
| `care` | `basic` · `plus` · `care` — מוסיף שורת אחזקה חודשית |
| `discount` | אחוז הנחה. מעל 10 דורש אישור בעלים |

העמוד מחשב סכום, מע"מ, פיצול לשני תשלומים ולוח זמנים, ומייצר מספר הצעה ותאריך תפוגה אוטומטית.
כפתור האישור פותח וואטסאפ עם נוסח חתימה מוכן.
