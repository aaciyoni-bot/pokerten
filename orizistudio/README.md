# ORIZISTUDIO

אתר השיווק והמכירות של ORIZISTUDIO, יחד עם שלדי הנישה ותשתית סגירת העסקה.

## מבנה

| קובץ | מה זה |
|---|---|
| `index.html` | האתר הראשי: הצעת הדמו החינמי, תיק עבודות אמיתי, סוגי אתרים, חבילות ומחירים, פלחי לקוחות, flow העבודה ושאלות נפוצות |
| `portfolio.js` | קטלוג העבודות: שם, קטגוריה, תיאור, קישור חי וצילום מסך. עריכת התיק נעשית בקובץ הזה בלבד |
| `shots/` | צילומי מסך אמיתיים של האתרים שבנינו, 640 פיקסל רוחב. באתר מוצג מבחר, לא כל התיק |
| `gate.js` | שער הכניסה לאזור המנהל. נטען ב-`pipeline.html` וב-`quote-builder.html` בלבד — ההצעה שהלקוח מקבל פתוחה |
| `quote-builder.html` | **הכלי של הסוכנת.** טופס עם תצוגה חיה שמייצר את הקישור להצעה ואת הודעת הוואטסאפ, ומראה לה כמה היא מרוויחה מהעסקה |
| `proposal.html` | עמוד ההצעה הדיגיטלית עצמו. נשלח כקישור אישי לכל לקוח, כולל אישור וחתימה |
| `STRATEGY.md` | התוכנית העסקית והשיווקית: פילוח לקוחות, מחירון, תוכנית שיווק, תגמול אשת מכירות, תשתיות ו-flow סגירת עסקה |
| `demos/base.css` | ספריית הרכיבים המשותפת. כל שלד נישה טוען אותה ומשנה רק טוקנים |
| `demos/*.html` | שישה שלדי נישה לבניית דמו חינם ללקוח בעשרים דקות: משרד עו"ד, מספרה, מוסך, קליניקה, חנות ודף אירוע. אלה כלי ייצור פנימי, לא תיק העבודות |

## איך מוסיפים עבודה לתיק

1. מצלמים את האתר החי ברוחב 1200 פיקסל, שומרים כ-JPEG ברוחב 640 בתיקיית `shots/`.
2. מוסיפים שורה ל-`portfolio.js` עם שם, קטגוריה, תיאור בשורה אחת, קישור חי ושם קובץ הצילום.
3. קטגוריה חדשה נוצרת מאליה — צ׳יפ הסינון באתר נבנה מהקטגוריות שבקובץ.
4. פריט בלי קישור ציבורי: מציבים `u:null` והכרטיס יוצג בלי לינק, עם הערה מתאימה.

## איך בונים דמו חינם ללקוח ב-20 דקות

1. בוחרים את השלד הקרוב ביותר מתוך `demos/`.
2. משכפלים לקובץ חדש בשם העסק.
3. משנים בראש הקובץ את חמשת הטוקנים בלבד: `--brand`, `--brand-soft`, `--accent`, `--alt`, `--ink`.
4. מחליפים שם, כתובת, טלפון, שירותים ומחירים.
5. מורידים את שורת ה-`ribbon` העליונה כשזה הופך לאתר אמיתי של לקוח.
6. מעלים לכתובת זמנית ושולחים את הקישור בוואטסאפ.

## איך שולחים הצעת מחיר

**הדרך הרגילה: פותחים את `quote-builder.html`.** ממלאים שם, עסק, טלפון, חבילה ותוספות,
והכלי מחשב הכול, מציג תצוגה חיה של ההצעה, ומייצר קישור אישי והודעת וואטסאפ מוכנה
בלחיצת העתקה. הוא גם מציג לסוכנת את העמלה שלה על העסקה ואת העמלה החוזרת מהאחזקה.

כפתור הוואטסאפ נעול עד שהיא מסמנת שקיבלה אישור טלפוני לשלוח הודעה ותיעדה אותו — כדי
שסדר הפעולות של סעיף 30א לחוק התקשורת יישמר בפועל, לא רק על הנייר.

**הדרך הידנית:** `proposal.html` נבנה מפרמטרים בכתובת, ואפשר לבנות קישור גם בלי הכלי:

```
proposal.html?biz=מספרת+נוגה&name=נוגה+לוי&pack=pro&addons=logo,content&care=plus&discount=10
```

| פרמטר | ערכים |
|---|---|
| `biz` | שם העסק |
| `name` | שם איש הקשר |
| `pack` | `nano` · `one` · `pro` · `business` · `shop` |
| `addons` | רשימה מופרדת בפסיקים: `logo` `content` `lang` `access` `bot` `booking` `photo` `landing` |
| `care` | `basic` · `plus` · `care` — מוסיף שורת אחזקה חודשית |
| `discount` | אחוז הנחה. מעל 10 דורש אישור בעלים |
| `phone` | טלפון הלקוח, מוצג בכותרת ההצעה |
| `agent` | שם הסוכנת, מוצג בתחתית |
| `note` | הערה אישית שמופיעה בראש ההצעה |
| `valid` | תוקף ההצעה בימים. ברירת מחדל 14 |

תוספת עם כמות נכתבת `key:qty`, למשל `addons=logo,content:3,lang:2`.

העמוד מחשב סכום, מע"מ, פיצול לשני תשלומים ולוח זמנים, ומייצר מספר הצעה ותאריך תפוגה אוטומטית.
כפתור האישור פותח וואטסאפ עם נוסח חתימה מוכן.

## אזור המנהל

`pipeline.html` ו-`quote-builder.html` נעולים מאחורי מסך התחברות. משתמשים קיימים:

| שם משתמש | תפקיד |
|---|---|
| `JENNI` | הסוכנת |
| `YONI` | בעלים |

הסיסמה נבדקת בדפדפן מול hash ב-`gate.js`. **לכן זו הגנה מפני כניסה מזדמנת בלבד —
מי שיפתח את קוד המקור יעקוף אותה.** ההגנה האמיתית היא Deployment Protection של Vercel,
שחוסמת בשרת לפני שהדף בכלל נטען. השער נועד לשבת מעליה, לא במקומה.

**הוספת משתמש או החלפת סיסמה:** מריצים djb2 על `שם:סיסמה` באותיות קטנות ומוסיפים
ל-`USERS` בראש `gate.js`. למשל בפייתון:

```python
def djb2(s):
    h = 5381
    for ch in s:
        h = ((h * 33) ^ ord(ch)) & 0xFFFFFFFF
    return format(h, 'x')
print(djb2('jenni:123456'))   # 4a19049e
```

`proposal.html` נשאר פתוח בכוונה — הלקוח צריך להיכנס אליו בלי סיסמה.
